# Scroll test

Run this on every script before delivering it. Be the viewer, not the writer.

## The viewer

It's 11:40 PM. They're 19–28, lying in bed, and this is the 40th reel in a row. Their thumb is already moving. They've seen every template hook. They don't know the creator and owe them nothing. They *will* send something to a friend tonight; the only question is whether it's this one.

## Pass 1: second by second

Walk the script in time order. Go word by word for the first three seconds, then line by line. At each point, ask:

- Do I know what this is about yet? (If not by about second 2, it's confusing → swipe.)
- Do I need the next line? Or do I already know where it's going? (→ swipe)
- Is anything happening on screen right now?

Mark the first **SWIPE** point honestly. Fix it. Then find the next one.

## Pass 2: four verdicts, one line each

1. **Stop:** would the first frame plus the first line stop *this* viewer? Why?
2. **Hold:** where is the weakest stretch? Which line could be deleted with nothing lost? (Delete it.)
3. **Payoff:** is the ending better than what the hook promised, or at least equal to it? Does it end *on* the payoff?
4. **Send:** who would they send it to, and what would they type? If there's no honest answer, the video isn't done.

## Pass 3: smell and cut

- Run the AI-tells list from human-voice.md. Rewrite any line that has the shape, not just the word.
- Cut 15–20% of the words. Each sentence should either move the story or be funny/beautiful enough to stay.
- Check that every claim is true, or obviously fiction.

## Reporting

Don't show this pass to the user unless they ask. Just deliver the better script. If the user asks for a critique of *their* script, report the SWIPE points and the four verdicts in a few plain lines each, then give the rewrite.

For a deliberately harsh, independent review (only when the user asks for one), give a separate subagent nothing but the script and this file, so it judges cold. Then revise from what it says.
