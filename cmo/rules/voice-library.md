# Brand Voice Library

## Purpose

Build and maintain a living library of proven hooks, CTAs, caption styles, visual patterns, and content formulas that work for the brand. This library gets smarter with every post — it's the brand's institutional memory for what resonates.

## Auto-Build Philosophy

The voice library should grow automatically through three channels:
1. **From competitor research** — Extract what works for competitors and adapt it
2. **From content creation** — Flag every new hook, CTA, and visual approach used
3. **From performance analysis** — Promote top performers, demote or remove underperformers

Never wait for the user to manually curate. Build proactively. But mark items with their source and performance data so the user can see what's proven vs. what's adapted vs. what's untested.

## Caption Structures

### The Story Arc
**Pattern:** Hook → Relatable situation → Turning point → Insight/Lesson → CTA
**Best for:** Personal brand posts, transformations, case studies
**Platform:** Instagram, LinkedIn
**Example structure:**
```
{Hook — bold first line}

{2-3 sentences painting the relatable "before" scenario}

{The turning point — what changed}

{The insight — what was learned}

{The lesson — actionable takeaway}

{CTA}
```

### The Value List
**Pattern:** Hook → Numbered points with brief explanations → Summary → CTA
**Best for:** Educational content, tips, resources
**Platform:** X/Twitter threads, LinkedIn, Instagram carousels
**Example structure:**
```
{Hook with specific number}

1. {Point} — {brief explanation}
2. {Point} — {brief explanation}
...

{Summary insight}

{CTA — save this for later}
```

### The Hot Take
**Pattern:** Bold statement → Supporting evidence/reasoning → Nuance → Discussion CTA
**Best for:** Thought leadership, engagement-driving, controversy
**Platform:** LinkedIn, X/Twitter
**Example structure:**
```
{Controversial opening statement}

{Why you believe this — 2-3 supporting points}

{The nuance — "BUT here's the thing..."}

{Question CTA — "Am I wrong? Tell me in the comments"}
```

### The Micro-Story
**Pattern:** Hook → Ultra-short story (3-5 sentences) → Punchline/Lesson → CTA
**Best for:** Quick engagement, relatable moments
**Platform:** X/Twitter, Instagram, LinkedIn

### The Framework
**Pattern:** Hook → Name the framework → Explain each step → Proof it works → CTA
**Best for:** Thought leadership, authority building, saves
**Platform:** LinkedIn, Instagram carousels

### The Myth-Buster
**Pattern:** "Myth: {common belief}" → "Reality: {truth}" → Evidence → What to do instead → CTA
**Best for:** Educational, counter-intuitive insights
**Platform:** All platforms

## Maintaining the Voice Library

### When to Update
- **After every competitor research session**: Add adapted hooks and strategies
- **After every content calendar creation**: Register new hooks, CTAs, and visual approaches used
- **After every performance analysis**: Promote winners, demote losers, add learnings
- **When the brand voice evolves**: Update the voice definition section

### How to Update
1. Read the existing `.growth/voice-library.md`
2. Add new entries to the appropriate section
3. Update performance data for existing entries when new data is available
4. Move items between sections as their status changes (untested → proven, or proven → underperformer)
5. Update the "Last Updated" date
6. Keep the file organized — if a section gets too long, archive old/low-performing entries

### Rating System
Use a simple star rating based on performance:
- **5 stars**: Top 10% engagement — use this pattern frequently
- **4 stars**: Above average — reliable performer
- **3 stars**: Average — works but nothing special
- **2 stars**: Below average — use sparingly
- **1 star**: Underperformed significantly — avoid or rethink
