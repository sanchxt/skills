# Game Lanes

Use these lanes for fast views and subscriber growth. Refresh with current browsing when the user asks for "today", "latest", or current targets.

## Priority 1: Roblox Brainrot And Trend Games

Best for raw Shorts velocity because the audience already expects chaotic, short, caption-heavy clips.

Use for:

- rare item reveals
- stealing or defending mechanics
- rich-from-zero runs
- update reactions
- admin events
- mistakes noobs make
- "this is still broken" tactics
- before/after account progress

Starting watchlist as of 2026-06-20:

- Grow a Garden / Grow a Garden 2
- Steal a Brainrot
- Brookhaven RP
- Blox Fruits
- Blade Ball
- Anime-style battleground games
- horror Roblox games around new updates
- any Roblox game currently dominating player count, YouTube search, or Shorts trends

## Priority 2: Evergreen Sandbox Games

Use when Roblox clips are not available or when a broader audience is needed.

- Minecraft: survival myths, seeds, builds, mobs, traps, speedrun mistakes.
- Fortnite: new items, mythic weapons, chapter/season changes, creative maps, fails.
- GTA 5 / GTA Online: money methods, stunts, glitches, police chases, roleplay chaos.

## Priority 3: Horror And Mascot Games

Use when new chapters, trailers, or updates drop.

- Poppy Playtime
- Garten of Banban-style games
- Roblox horror copies and original horror experiences
- indie horror games with strong monster designs

Good angles: "I survived X", "the scariest room", "this jump scare is unfair", "secret ending".

## Priority 4: Mobile And Casual Viral Games

Use for broad low-friction clips, especially if gameplay is easy to capture.

- Stumble Guys
- Geometry Dash
- Subway Surfers-style background gameplay only when paired with original narration
- current viral mobile puzzle or rage games

## Game Selection Heuristic

Pick games with at least two of these:

- active updates or events this week
- visible rare items, rewards, ranks, skins, pets, or money
- simple stakes a viewer understands in one second
- search demand from kids/teens/young gamers
- comments naturally asking for "part 2"
- easy screen recording with clear vertical framing
- repeatable challenge, secret, fail, or comparison formats

Avoid spending time on games that require long explanation, have slow visual payoff, or only appeal to an older niche unless the user explicitly wants them.
