# Story structures

Write the words with the `short-form-craft` skill (angle, hooks, retention, human voice, critic pass). This file covers how the *video* is structured around them. Time ranges are for a 30–45 s vertical cut; scale for 16:9 long versions.

## Every video

- **Frame 0 is already moving and already says something.** No fade from black, no logo, no "Hey guys". The first frame doubles as the cover.
- **The hook is visual *and* verbal.** Even muted, the first 2 seconds must make a stranger stop: big text (7 words or fewer), a notification popping, a number, a striking before/after.
- **One idea per 2–4 seconds** on screen. If a beat needs more, split it.
- **Payoff before the CTA.** Show the result working, then ask.
- **CTA is specific:** "DM 'RECEPTIONIST' and we'll set one up for you", "Comment WORKFLOW for the template", "eravue.com". End card 2–3 s, with the logo there (and only there, in ads).

## 1. Automation / product demo

| Time | Beat | On screen |
|---|---|---|
| 0–2 s | Hook: the moment of pain or the result ("It's 2 AM. A patient messages your clinic.") | Phone lights up with the message; time stamp |
| 2–6 s | Stakes: what normally happens ("Nobody replies. They book somewhere else.") | Unanswered message greys out; a competitor/lost tag |
| 6–10 s | Reveal: the system ("This AI receptionist replies in 3 seconds.") | The flow canvas appears, the **music drop** |
| 10–30 s | How it works: 3 steps max, one visual each (reads the message → checks the calendar → books + updates the CRM) | Camera travels node to node; chat fills in on the phone in sync |
| 30–38 s | Result: what the owner gets (booked slot, CRM row, owner alert) | Calendar event pops, CRM row, notification |
| 38–45 s | CTA | End card |

Label demos as demos ("built for a demo clinic"). Never claim a live integration that isn't real.

## 2. AI / tech news explainer

| Beat | On screen |
|---|---|
| Most surprising true fact first | Big headline (Paper: serif headline + source line) |
| What happened, in one line a non-techie gets | One simple diagram or 2–3 key visuals |
| What it means for *you* (the business owner) | Concrete example in their world |
| What to do | 1–3 actions, numbered |
| The take or open question → "follow for part 2" | Founder's opinion in a pull-quote style |

Verify every fact with a search. Keep sources and dates in the notes, and show a small source line on claims. Post within 24–48 h of the news.

## 3. Case study / results

Result number first ("Replies in 3 seconds, 24/7") → who (with permission, or "a dental clinic in Pune") → the problem before → what was built (visual walkthrough, fast) → the result (real numbers only, a before → after count-up) → CTA. Bento or Paper. **Only real clients and real numbers. Leave `[REAL: …]` slots and ask.**

## 4. Tutorial / how-to

Show the finished thing working (0–3 s) → "here's how to build it" → 3–5 steps, each with the actual tool on screen (Terminal look for code and prompts, real screenshots with Sketch annotations) → result again → "Comment WORD and I'll send you the workflow". Make sure the thing really gets sent.

## 5. Offer / service ad

| Time | Beat |
|---|---|
| 0–2 s | Pain hook (question or call-out: "Still replying to leads by hand?") |
| 2–6 s | Agitate (what it costs them, in their words) |
| 6–15 s | The offer: what Eravue does, the outcome, how fast |
| 15–22 s | Proof (a real result, a demo glimpse, a logo row only if real) |
| 22–30 s | CTA + end card |

Make **3 hook variants** with the same body, as separate compositions sharing scenes: pain question, bold result claim (true), and pattern interrupt (a striking visual). Keep a music-only, text-led variant for sound-off placements.

## Hook patterns that work visually

- **Notification pop:** a phone lock screen with a message or missed call arriving.
- **Number slam:** "3 sec" huge, then what it means.
- **Before/after split:** messy versus automated.
- **Question in big type** with the key word in accent.
- **The result already happening:** a booking landing in a calendar.
- **"This is [X]" + the thing** (as in the current demos: "This is a WhatsApp AI receptionist").

## Storyboard format (show this before building)

| # | Beat id | Words | Visual | Hero motion | Text / caption | Music | SFX |
|---|---|---|---|---|---|---|---|
| 1 | h1 | "It's 2 AM. A patient messages your clinic." | Lock screen, WhatsApp notification | Notification drops in on "messages" | chunk captions | soft intro | pop |
| 2 | r1 | "This AI receptionist replies in 3 seconds." | Canvas reveal, AI node lit | Camera pull-back on "receptionist" | "3 seconds" accented | **drop** | whoosh |

Get the user's OK on the storyboard, look and music direction before building scenes.
