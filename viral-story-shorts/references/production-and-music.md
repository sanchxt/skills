# Production, clips, music, and rights

Read when the user requests clip sourcing, interview moments, edit timelines, song choices, beat/drop placement, platform packaging, or a publishable production plan.

## Visual plan

Assign every clip a narrative function:

| Function | Useful visual |
|---|---|
| Recognition | iconic face, uniform/costume, venue, award, familiar scene |
| Pressure | loss, empty set, bench, rejection headline, strained interview, old behavior |
| Passage | one date card, matched shots, restrained montage |
| Pivot | audition/call/training/meal/service/action tied to the decision |
| Proof | performance, score, speech, changed behavior, reaction, callback |
| Meaning | close-up, embrace, walk-off, held image, before/after match |

Prefer the actual moment under discussion. Generic B-roll weakens proof. Avoid unrelated “sludge” footage that competes with the narrative.

## Captions and first frame

- Build the first frame for a moving thumb: one dominant subject, visible motion/expression, high contrast, one instantly readable idea.
- Opening text is normally 3–8 words.
- Burned-in captions should be manually corrected and broken by meaning.
- Emphasize a few key words; do not animate every word merely to create activity.
- Keep text and faces inside a conservative 9:16 safe area and verify against each platform UI.
- Make the premise understandable without sound while rewarding sound-on viewing.
- Export a clean, high-resolution, watermark-free master.

## Authentic clip schema

For each interview or scene option provide:

| Field | Required content |
|---|---|
| Source | publisher/channel, exact title, direct URL, date |
| In/out | verified timestamp range |
| Content | speaker/action and short exact quotation if needed |
| Function | hook, credibility, pressure, pivot, proof, or ending |
| Label | speaker/date/context to show on screen |
| Rights | licensed, official remix, public domain, permission needed, or unknown |
| Fallback | original voiceover + licensed/owned visual alternative |

Never invent timestamps. If a video cannot be inspected, give search terms and label the timestamp as unverified.

## Music selection

Select music by emotional function before trend status:

- elegiac → triumphant for absence/return;
- tense → controlled for discipline or character maturity;
- nostalgic → euphoric for rediscovery;
- minimal → explosive for one decisive performance;
- warm → cathartic for healing or community.

For each candidate verify at production time:

- exact track version/edit/remix;
- availability on TikTok, Instagram, and YouTube in the user's region;
- personal/business/commercial account restrictions;
- usable duration;
- intro, riser, downbeat/drop, chorus, and outro timestamps in that version;
- lyric conflicts with voiceover or story meaning;
- license/rights status;
- a rights-safe fallback with similar structure.

Trends and catalogs are unstable. Search current platform trend/library pages and recent usage; never claim that a track is trending from memory.

## Drop architecture

Default arc:

1. Hook: recognizable texture/pulse or restrained tension; keep the voice dominant.
2. Pressure: sparse arrangement under facts/dialogue.
3. Pre-pivot: riser, filtering, reduced percussion, held note, or brief silence.
4. Pivot/proof: align the first strong downbeat, chorus, bass entrance, or harmonic release with the irreversible decision or first visual proof.
5. Meaning: let the payoff breathe, then resolve or loop cleanly.

Do not place the main drop at an arbitrary second. Map the selected track to the final narration and clip timings. Duck music under voice and authentic dialogue. Use natural sound as an attention reset when it increases credibility.

## Rights and originality

Treat availability as different from permission.

- Use licensed, permissioned, original, public-domain, official press, or in-product remix assets when possible.
- Platform music licenses are platform-, region-, account-, content-, and duration-dependent; do not assume a TikTok/Instagram license covers YouTube or an external editor export.
- YouTube music added outside Shorts creation tools may receive standard Content ID claims/removal requests. Active claims can block 1–3 minute Shorts.
- TikTok commercial/branded activity should use the Commercial Music Library or separately cleared audio.
- Instagram's licensed library is generally for personal, non-commercial use; Meta Sound Collection supplies commercial-safe options.
- Credit, cropping, borders, captions, short excerpts, pitch/speed changes, or “no copyright intended” do not create permission.
- Copyright exceptions are fact-specific and jurisdiction-dependent. State uncertainty; do not give a legal guarantee.
- Meaningful commentary and editing may satisfy a platform's originality/monetization review while copyright risk still remains.

## Cross-platform master

Create a voiceover-led clean master, then package natively:

- TikTok: concise searchable caption, safe-zone check, account-appropriate native sound.
- Instagram: no competing-app watermark, readable profile-grid cover, send-worthy caption, optional Trial Reel.
- YouTube: clear subject/transformation title, series/playlist when useful, appropriate Shorts/Audio Library sound.

Do not compare raw view counts as if platforms count or distribute them identically.
