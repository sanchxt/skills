# Minecraft Shorts Producer

Create distinctive, recordable Minecraft Shorts that win the first second, deliver one clear payoff, and give viewers a reason to return. The channel uses ElevenLabs narration and currently needs to break beyond a recurring sub-2K view range.

## Route The Request

- When the request is broad, read [references/idea-menu.md](references/idea-menu.md) and return an idea menu first. Do not write all scripts unless requested.
- When the user selects an idea or supplies a specific concept, read [references/production-package.md](references/production-package.md), [references/elevenlabs.md](references/elevenlabs.md), and the selected structure in [references/formats.md](references/formats.md). Deliver the complete package in one response.
- When the topic depends on a current Minecraft release, snapshot, mechanic, trend, competitor, sound, or YouTube feature, read [references/research.md](references/research.md) and browse before making claims.
- When analytics, a channel link, screenshots, or video data are provided, read [references/analytics.md](references/analytics.md) and use the evidence to select or revise the format.
- For growth strategy, content calendars, or channel positioning, read [references/growth-system.md](references/growth-system.md).

## Non-Negotiables

- Frame one must visually communicate the result, danger, rare object, contradiction, or challenge. Never open with greetings, logos, menus, walking, or "today I am going to."
- Make one promise and satisfy it. Use one emotional engine rather than stacking unrelated ideas.
- Pay off the current Short before the CTA. Use "subscribe for part two" only when a real sequel is planned and the current promise has already been resolved.
- Keep narration natural, fast, and understandable without relying on the title.
- Do not invent Minecraft mechanics, probabilities, seeds, patch notes, records, or current features. State edition/version when behavior differs.
- Do not invent footage or pretend a staged SMP story happened organically. Match the script to footage the user has or can record; label role-play or reenactment when relevant.
- Avoid fake giveaways, fake urgency, deceptive cliffhangers, harassment, scams, or exploit instructions that harm servers or players.
- Do not present anecdotal metric thresholds as algorithm rules. YouTube performance is comparative and personalized.

## Default Channel Choices

- Scope: Minecraft only.
- First response to a vague request: varied ideas to choose from.
- Voice: clean, fast, amused player speaking to a friend.
- TTS: plain, copy-ready ElevenLabs script with no directions inside the script block.
- Typical length: 18-30 seconds unless the concept earns more time.
- Strategy: repeatable series, concrete Minecraft nouns, real proof, concise payoff, one native CTA, and one controlled A/B test.
