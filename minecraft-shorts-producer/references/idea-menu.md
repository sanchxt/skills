# Idea Menu

Use this when the user asks broadly for Minecraft Shorts, growth ideas, or a batch without selecting a concept.

## Default Menu

Offer 8-10 ideas that span at least six distinct formats from `formats.md`. Do not return ten cosmetic variations of the same danger story.

For each idea include:

| Field | Requirement |
|---|---|
| Concept | One specific, recordable Minecraft premise |
| Format | Myth, clutch, mistake, rare fact, ranking, SMP story, transformation, update, speedrun, or comment test |
| Opening hook | The first spoken sentence, normally 8-12 words |
| First frame | Exact visual needed before the first second ends |
| Payoff | What the viewer will definitely see resolved |
| CTA path | The natural next test, choice, or sequel |
| Production level | Easy, medium, or advanced |
| Why it can work | Topic appeal plus emotional engine; no viral guarantees |

Finish by asking the user to choose an idea number. If the user chooses one, move directly to the complete production package without asking questions that can be reasonably inferred.

## Selection Heuristic

Prefer ideas with at least three of these:

- recognizable Minecraft noun: diamonds, Warden, creeper, Ender Dragon, netherite, ancient city, villager, elytra
- consequence: death, lost item, failed run, trapped base, wasted resource
- testable question: does it work, which wins, can this survive, what happens if
- visible novelty: obscure interaction, unusual combination, transformation, new mechanic
- measurable result: three methods, one heart, 100 blocks, five attempts
- repeatable series potential
- a result that can be shown clearly in vertical gameplay

Avoid slow lore that needs extensive context, generic "Minecraft but" clones, weak facts with no visual proof, and concepts that require fabricated footage.

## Topic Mix For A Typical Menu

- 2 myth or experiment ideas
- 2 danger, clutch, or challenge ideas
- 1 mistake or tutorial idea
- 1 rare fact or item idea
- 1 community/comment-driven idea
- 1 ranking, SMP, build, speedrun, or timely update idea

Vary the mix when channel data identifies a strong repeatable winner.
