# Deliverable templates

Use only the sections needed. Keep paste-ready narration isolated from production notes.

## Scout package

````markdown
## [Subject] — [one-line premise]

- Why now / why evergreen:
- Format verdict: [Story-first / Edit-first / Works for both]
- STORY: [x/10] — [weakest dimension]
- EDIT: [x/10] — [weakest dimension]
- Voiceover angle: [question → payoff]
- Music-led angle: [emotion; first image → drop image]
- Source/clip feasibility: [proof and rights caveat]
- Sources: [direct links]
````
