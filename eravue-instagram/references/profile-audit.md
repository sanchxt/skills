# Profile audit: find what's missing

Audit takes 2-4 minutes per account. Write down **evidence you saw**, never assumptions. The DM will quote one piece of it, so it has to be true and specific.

## 1. Profile header

| Check | Gap if... | Service |
|---|---|---|
| Bio says what they do, where, and for whom | Vague ("living my dream ✨"), no city, no offer | brand-design, social-media |
| Bio link | None; Linktree/bio.site only; link to WhatsApp only; broken or expired link | website |
| Contact buttons (Call, Email, WhatsApp, Book) | Missing; only "DM for price/booking/order" | ai-chat-agents, website |
| Highlights | None; no reviews/testimonials, no prices/menu, no "how to book" | social-media, website |
| Profile photo / name | Blurry logo, inconsistent name across bio and website | brand-design |
| Account category | Personal account used for business | (note only) |

## 2. Content (last ~9 posts)

| Check | Gap if... | Service |
|---|---|---|
| Last post date | Over 30 days ago, or long gaps | social-media |
| Reels share | No or few reels while competitors post them | video-editing, social-media |
| Reel quality | No captions/subtitles, no hook in first 2 seconds, raw footage, bad audio, long intros | video-editing |
| Creative quality | Phone photos on cluttered backgrounds, Canva templates everyone uses, text-heavy posters | ai-content, brand-design |
| Views vs followers | Reels getting a small fraction of followers in views | video-editing, social-media |
| Captions | No call to action, no price, no way to book | social-media |

## 3. Comments (open 2-3 recent posts)

This is the strongest evidence source:
- **"price?" / "rate?" / "details?" / "how to order?" comments with no reply, or "DM'd you" with no follow-up.** → ai-chat-agents / lead-followup. Count them: "6 price questions on your last 3 reels, none answered" is a powerful, true hook.
- Complaints about slow replies ("I messaged, no response").
- Happy customer comments that aren't saved anywhere (no reviews highlight) → social-media.

## 4. Bio link and website (open it)

| Check | Gap if... | Service |
|---|---|---|
| Exists | No site at all | website |
| Mobile | Text tiny, buttons overlap, horizontal scroll, popups covering everything | website |
| Speed | Takes more than ~3s to show content on mobile. Optional: PageSpeed Insights (pagespeed.web.dev) mobile score under ~50 | website, seo |
| Enquiry path | No WhatsApp/call button, contact form broken or buried, no booking | website, lead-followup |
| Basics | No SSL warning, © 2019 footer, broken images, "Lorem ipsum", dead links | website |
| Google | Search "<business name> <city>": no Google Business Profile, few reviews, site not showing | seo |

Check the website in the built-in browser or a DevTools page; it doesn't need Instagram's login.

## 5. Extra signals (optional, boost score)

- Running Meta ads (Ad Library) → has budget.
- Hiring posts ("we're hiring a social media executive / video editor / receptionist") → paying salary for something Eravue does.
- New launch, new branch, rebrand, festive or wedding season push.
- Good Google reviews but weak Instagram, or the other way round.

## Pick ONE gap for the DM

Choose the gap that is (a) most visible to the owner, (b) costing them money in a way they'll feel, (c) fixable by Eravue fast. Priority order when several exist:
1. Unanswered enquiries (price comments, "DM for price" with visible lost interest): lost money now.
2. No website / broken link while they're clearly selling.
3. Weak reels on an active account (they're already trying).
4. Stale posting / weak creatives.

Other gaps go in "Gaps found" for the call later, not into the first DM.

## Score (1-5)

Use eravue-outreach qualification.md, with these Instagram specifics:

- **5:** owner-run, active in the last 2 weeks, clear money-losing gap with evidence (unanswered price comments, no site while selling), plus a budget signal (ads, physical location, premium pricing) or a matching proof niche.
- **4:** good fit, clear gap, no budget signal.
- **3:** fit plausible, gap minor or account small/inactive. Only if the batch is short.
- **1-2:** don't track.

Sensitivity: health businesses are fine to pitch as businesses (a dental clinic). Never comment on anyone's appearance, body, health or personal life.

## Evidence line for the tracker

`--signal` = the facts ("Linktree only; 6 unanswered price comments on last 3 reels; last post 2d ago; 4.2k followers").
`--angle` = what you'll offer ("free 1-page mockup" / "60s video of an auto-reply for their price comments").
